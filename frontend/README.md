# Angular client

This Angular 22 client provides the GTD incident input form and calls the local Flask API through `proxy.conf.json`.

From this directory, install the locked dependencies and start the local interface:

```powershell
npm ci
npm start
```

The system needs Node.js 22.22.3 or newer in the 22.x line, or 24.15.0 or newer in the 24.x line. See the root [README](../README.md) for model training, backend startup, CI, and GitHub Pages limitations.
